Privacy

Ultimo aggiornamento: 16 novembre 2026

MioCash è un'app per tenere i conti di casa. È pensata perché i tuoi dati restino tuoi: non c'è un account MioCash, non c'è un server MioCash e nessuno, oltre a te, vede i tuoi movimenti.

Dove sono i tuoi dati

  • Conti, movimenti, causali e impostazioni sono salvati solo sui tuoi dispositivi (telefono Android, iPhone, PC Windows). Su Android e Windows il database è cifrato.
  • MioCash non raccoglie statistiche d'uso, non usa pubblicità e non contiene sistemi di tracciamento.
  • Quando esporti un archivio per passarlo a un altro dispositivo, il file è cifrato con una password scelta da te e lo invii tu, con il mezzo che preferisci.

Backup su Google Drive (facoltativo)

Nell'app Android puoi attivare il backup automatico su Google Drive. Se lo attivi:

  • MioCash chiede a Google soltanto il permesso di gestire i file creati da MioCash (permesso drive.file). Non può vedere, leggere o modificare gli altri file del tuo Drive.
  • Ogni backup è cifrato sul telefono, con una password scelta da te, prima di essere caricato. Su Google Drive arriva un file illeggibile senza quella password: né Google né altri possono vederne il contenuto.
  • I file vanno nella cartella «MioCash» del tuo Drive, sul tuo account. MioCash legge l'indirizzo email dell'account solo per mostrartelo nelle impostazioni dell'app; non lo invia a nessuno.
  • I dati ricevuti dalle API di Google servono solo a salvare e ripristinare i tuoi backup. Non vengono trasferiti a terzi, né usati per pubblicità o per altri scopi.
  • Puoi fermare il backup quando vuoi dall'app (Impostazioni › Backup su Google Drive › Scollega) oppure togliere il permesso dal tuo account Google, nella pagina App e servizi collegati. I file già salvati restano sul tuo Drive finché non li elimini tu.

L'uso delle informazioni ricevute dalle API di Google rispetta le norme sui dati utente dei servizi API di Google, compresi i requisiti di uso limitato.

Collegamenti a internet

  • Aggiornamenti: l'app controlla su GitHub se c'è una nuova versione e, se lo chiedi, la scarica. GitHub riceve l'indirizzo IP del dispositivo, come per qualsiasi pagina web.
  • Questo sito è ospitato da GitHub Pages e usa i caratteri di Google Fonts; non usa cookie né strumenti di analisi.
